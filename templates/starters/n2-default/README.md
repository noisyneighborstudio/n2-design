# N2 Default Starter

A clean, functional HTML starter that follows N2 Design principles.

## What's Included

- `DESIGN.md` - Complete N2 Design system documentation
- `index.html` - Starter HTML with N2-styled components

## Design Principles

1. **Clarity over cleverness** - Simple, understandable interfaces
2. **Function over decoration** - Purpose-driven design
3. **Consistency** - Predictable patterns throughout
4. **Real user needs** - Solve actual problems

## Usage

This starter is automatically copied when you create a new project in N2 Design. It provides:

- CSS custom properties for the design system
- Basic component examples (cards, buttons, grid)
- Responsive layout structure
- Clean, semantic HTML

## Customization

Feel free to modify the DESIGN.md to fit your project's needs. The design system is meant to be a starting point, not a rigid constraint.
